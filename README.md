# SehatKu Catering

Sistem Pemesanan Catering Berbasis Web dengan Fitur Kalkulator Kalori pada UMKM Catering Sehat Pekanbaru.
Project Semester Framework (Laravel) - Politeknik Caltex Riau.

## Menjalankan di lokal

```bash
composer install
cp .env.example .env
php artisan key:generate
# buat database: CREATE DATABASE sehatku_catering CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
php artisan migrate
php artisan serve
```

README lengkap akan ditulis pada commit terakhir.
